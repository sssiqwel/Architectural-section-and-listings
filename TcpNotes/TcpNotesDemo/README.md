# TcpNotesDemo

Исходный код учебного TCP-приложения на C# и .NET 10:

- `NotesServer` — сервер и общее хранилище в памяти;
- `NotesClient` — консольный клиент, который можно запустить в нескольких экземплярах;
- `TcpNotes.Tests` — модульные и сетевые проверки.

Инструкции по сборке, запуску и использованию находятся в [корневом README](../README.md).
